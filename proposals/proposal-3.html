The Protocol
01
Income Layer
EIP-3009

Clients sign a TransferWithAuthorization typed message offline. Circle's Gateway settles the USDC transfer on Arc — no approval step, no second wallet interaction. One signature → value credited.

signTypedData(TransferWithAuthorization)
→ Circle Gateway /v1/payments/settle
→ USDC on-chain, agent wallet credited
02
Data Layer
Arc RPC

The agent calls Arc testnet RPC directly for blockchain data — transaction counts, event logs, bytecode, USDC transfers. Claude synthesizes raw chain data into structured intelligence. All costs logged to the treasury ledger.

eth_getTransactionCount, eth_getLogs
eth_getCode → Claude synthesis
→ expense recorded: $0.005–$0.015
03
Capital Layer
USYC

Post-task, idle USDC above the $10 operating reserve is swept into Hashnote USYC via the Teller contract, earning ~4.85% APY. When reserves drop, USYC is redeemed automatically to restore liquidity.

balance > reserve × 1.5:
USDC.approve → Teller.deposit
→ USYC minted, yield accrues daily
