[01] Three-Layer Financial Architecture
↓
EIP-3009 Income
Clients sign a TransferWithAuthorization off-chain. Circle's Gateway settles the USDC transfer on Arc without a separate approval transaction — one signature, instant settlement.
// client signs typed data signTypedData({ type: "TransferWithAuthorization", from: client, to: agent, value: price, }) // Circle Gateway settles → // USDC credited on-chain
↑
x402 Expenses
When the agent needs external data, it calls Arc RPC directly — no micropayment needed since it's the same platform. Expenses are tracked internally for transparency.
// agent calls Arc RPC arc_rpc.eth_call({ to: contract, data: calldata, }) // result returned instantly // cost tracked: $0.005
◈
USYC Yield Engine
After every task, idle USDC above the $10 operating reserve is automatically deposited into Hashnote USYC via the Teller contract. Redeemed automatically when reserves run low.
// sweep logic if balance > reserve * 1.5: approve(teller, amount) teller.deposit(amount) // USYC minted ~4.85% APY
